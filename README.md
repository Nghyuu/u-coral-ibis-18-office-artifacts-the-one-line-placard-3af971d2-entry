A one-line museum placard for an ordinary office object — a stapler — written as if it were an ancient artifact dug from a lost civilisation, with a catalogue date, a material, and a donor.

Entry for the [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on make.fun.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
